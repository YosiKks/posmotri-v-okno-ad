# Проектная работа «Посмотри в окно»

Учебный проект Яндекс Практикума. Нужно было написать CSS для уже работающего приложения «Посмотри в окно» так, чтобы интерфейс соответствовал макету в Figma.

Приложение показывает видео из окон разных городов. Пользователь может выбрать ролик из списка карточек, искать видео по городу и времени суток и подгружать дополнительные карточки кнопкой «Показать ещё».

## Что сделано

Вся работа выполнена в файле `styles/style.css`. HTML-разметка и скрипт `scripts/script.js` остались без изменений.

- Лейаут страницы собран на flex: центрирование блока, расположение видео, формы и списка карточек, распределение элементов формы.
- Заданы размеры блоков, видео и картинок подогнаны через `object-fit` и `object-position`.
- Оформлены тексты: заголовок, названия полей формы, названия и описания карточек. Длинные названия обрезаются многоточием, описания ограничены через `line-clamp`.
- Сверстаны кастомные поле ввода и чекбоксы. Состояние выбранного чекбокса нарисовано через псевдоэлемент `::after`, а лейблы скрыты паттерном `.visually-hidden`.
- Сверстаны кнопки «Найти» и «Показать ещё» и состояния `:hover`, `:active`, `:focus-visible` для кнопок, полей, чекбоксов и карточек.
- Выбранная карточка подсвечивается классом `.content__card-link_current`, активная карточка и карточка при наведении оформлены отдельно.
- Прелоадеры и блок ошибки позиционируются поверх контейнера с видео и контейнера со списком карточек.
- На кликабельные элементы добавлен `cursor: pointer`.

## Структура проекта

```
.
├── fonts/            # шрифты и их подключение
├── scripts/
│   └── script.js     # логика приложения
├── styles/
│   ├── style.css     # основные стили (моя часть работы)
│   ├── preloader.css # стили прелоадера
│   └── error.css     # стили блока ошибки
├── index.html        # разметка
└── README.md
```

## Как запустить

Достаточно открыть `index.html` в браузере. Для загрузки видео и карточек нужен доступ в интернет: данные приложение берёт с сервера Практикума.

## Технологии

HTML, CSS (flex, псевдоклассы и псевдоэлементы, `:has()`), JavaScript (готовый скрипт из заготовки).
